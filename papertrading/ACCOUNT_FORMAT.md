# Формат чтения виртуального счёта

Каждая пара «стратегия × акция» сохраняет собственные `state.json`, события и журнал сделок. Никакие счета не объединяются и история не переносится.

Общий формат **для чтения** формирует [`service/account_record.py`](../service/account_record.py) из строки последнего опроса и состояния счёта. Его использует [веб-панель](../web/server.py). Поля:

| Группа | Поля |
| --- | --- |
| Идентичность | `account_id`, `symbol`, `strategy`, `timeframe`, `started_at` |
| Наблюдение | `status`, `paper_status`, `source`, `error`, `last_completed_bar` |
| Позиция и заявка | `position` (знаковое число акций), `side`, `pending`, `entry_price`, `mark_price` |
| Капитал и PnL | `initial_capital`, `equity`, `return_pct`, `open_pnl_rub`, `open_pnl_pct` |
| Активность | `closed_trades`, `last_event`, `orders_created`, `new_events` |

`pending` обозначает сигнал на следующую свечу, **не открытую позицию**. `open_pnl_*` равен нулю при `FLAT`; если позиция открыта, но цены для оценки нет, значение `null`. `return_pct` считается по всему капиталу счёта, `open_pnl_pct` — тоже от его начального капитала. При ошибке источника последний известный `state.json` остаётся видимым, а `status` показывает проблему опроса. Эти значения относятся только к одному независимому счёту.
