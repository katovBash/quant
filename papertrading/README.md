# Paper trading

Прежние 15 стратегий и 106 setup удалены 02.11.2026 после проверки месячной устойчивости; [журналы прошлых виртуальных событий](live/README.md) сохранены для аудита. Новые виртуальные счета для четырёх пар повторного касания 4H линии перечислены в [каталоге стратегий](../strategies/README.md). [Панель](../web/README.md) читает [актуальный статус](live/fleet_status.json); она показывает настройку счёта и результат последнего опроса отдельно.

## Новый запуск

После выбора и ручной сверки новой стратегии создайте отдельный JSON в [setups/fleet](setups/fleet/) по [шаблону](setup.template.json). Один setup задаёт одну пару «стратегия × тикер × интервал», капитал 1 млн ₽ и лимит новой позиции 10%. Проверить состав и расходы, затем запустить `python3 -u -m service.paper_fleet --once` для одного пробного опроса. Для непрерывного наблюдения: `python3 -u -m service.paper_fleet --poll-seconds 900`. При отсутствии setup процесс не запускается.

Fleet умеет находить завершённые стратегии с `selection.json` и создавать setup для выбранных акций. Поэтому новую папку стратегии создают только после [месячного экрана](../experiments/template/README.md), проверки Pine/Python и отдельного решения о paper trading. Источник свечей — MOEX ISS; статус `OK` означает успешный опрос, а не прибыль или наличие новой сделки.

## Статусы

[Месячные категории](../criteria/README.md) рассчитываются по новым виртуальным сделкам. `APPROVED_30D_PAPER` означает лишь продолжение бумажной проверки после 30 дней положительного результата и подтверждённых расходов. Это не разрешение на реальные деньги. Short-заём, дивиденды, биржевые лоты, возможные пропуски свечей и совпадение с TradingView проверяются отдельно. Числовой `stop_loss_pct` пока не реализован; `null` означает отсутствие стопа.
