# Стратегии

Новая [Turtle 55/20 на 1H](dennis-turtle-55-20-1h/README.md) зафиксирована для десяти бумаг из [эксперимента трёх правил](../experiments/three-trader-rules/README.md) и подключена к отдельным виртуальным счетам. Исторический рейтинг до расходов; в paper trading используются новые свечи и отдельная модель расходов.

Созданы три фиксированных варианта повторного касания 4H линии с EMA25: [wing 1, зона 0,5 ATR](line-retest-4h-wing1-zone05-slope/README.md) для IRKT и WUSH; [wing 1, зона 1 ATR](line-retest-4h-wing1-zone1-slope/README.md) для IRKT; [wing 2, зона 1 ATR](line-retest-4h-wing2-zone1-slope/README.md) для MGNT. IRKT в двух вариантах ведётся раздельно. Каждый вариант имеет Python-сигнал, Pine для ручной сверки, исторические месяцы и отдельный виртуальный setup. Исторические результаты до расходов и отобраны на просмотренной истории; у всех были убыточные месяцы. Статус paper trading показывает только новые наблюдения.

Прежние 15 кандидатов удалены после проверки коротких окон: у каждой из 106 пар «правило × акция» на просмотренной истории был хотя бы один убыточный календарный месяц. [Снимок аудита](../experiments/.history/retired-strategy-audit-2026-11-02/) и [журналы прежних виртуальных событий](../papertrading/live/) сохранены. Новые стратегии описываются по [шаблону](template/README.md); появление хорошей исторической строки само по себе не запускает торговлю.
