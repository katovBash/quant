# Тесты

[Шаблон проверок новой идеи](template/README.md) показывает, какие тесты нужны до перебора, перед переносом в стратегию и перед виртуальным счётом.

`tests/` проверяет, что расчёты и виртуальные сделки работают по заявленным правилам. Это не исторические результаты и не оценка прибыльности: такие таблицы находятся в [`experiments/`](../experiments/README.md).

| Папка | Что проверяет |
| --- | --- |
| [`ema`](ema/) | Расчёт сигналов, временные ограничения, бэктест и паритет ускоренного EMA-перебора. Здесь пока больше тестов, потому что реализованы прежде всего EMA-исследования; новые индикаторы получат свои проверки при добавлении кода |
| [`indicators`](indicators/) | Проверка формул ADX и RSI на известных крайних случаях и отсутствие заглядывания в будущие свечи |
| [`strategies`](strategies/) | Проверки точного Python-сигнала уже выбранных правил; сравнение Pine-сделок в TradingView остаётся ручной сверкой |
| [`experiments`](experiments/) | Новые одиночные сигналы RSI, ADX, четырёхточечных уровней и паттернов, причинность и формат расчёта до массового прогона |
| [`service`](service/) | Виртуальное исполнение, повторный опрос, пропуски свечей и неизменность параметров |
| [`criteria`](criteria/) | Исторический допуск и оценку новых сделок |

Из корня репозитория: `python3 -m unittest discover -s tests -t . -v`. `-t .` нужен, чтобы пакеты тестов не затеняли рабочие `service` и `criteria`.
