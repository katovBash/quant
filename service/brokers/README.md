# Брокерские подключения

Подключений к брокерам сейчас нет: сервис ведёт только собственный виртуальный счёт и не отправляет заявки. MOEX ISS в [`data_sources`](../data_sources/README.md) служит источником рыночных свечей, а не брокером.

Если позднее понадобятся Т-Инвестиции или Альфа-Инвестиции, для каждого потребуется отдельный адаптер рыночных данных и, при явном решении перейти к реальным заявкам, отдельный интерфейс исполнения. До этого нельзя считать цены MOEX, доступность short, лоты, комиссии или время ответа брокера взаимозаменяемыми. Брокерский адаптер не должен менять правила `strategy.py`; он нормализует данные и отчёт об исполнении.
