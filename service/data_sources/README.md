# Источники рыночных данных

Сейчас бумажный сервис использует [MOEX ISS](moex.py): он загружает часовые OHLCV-свечи TQBR и пропускает незавершённую свечу. Этот модуль **только читает котировки** и не отправляет заявки.

Если позже понадобится другой источник котировок, добавляем отдельный адаптер с тем же выходным форматом: `ts`, `end`, `open`, `high`, `low`, `close`, `volume`, упорядоченные завершённые свечи без дублей. Смена источника в действующем бумажном эксперименте требует нового журнала или документированной сверки истории, времени свечей и корпоративных событий.

Подключение брокера для реальных заявок — **другая задача**. Ни MOEX ISS, ни этот сервис сейчас не торгуют через брокера. Будущий брокерский адаптер не должен быть частью модуля рыночных данных; он потребует отдельного интерфейса заявок, управления риском и проверок исполнения.
