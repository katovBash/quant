# Quant

Исследование торговых правил, проверка стратегий на истории и виртуальная торговля по зафиксированным сигналам. Порядок работы от гипотезы до paper trading описан в [WORKFLOW.md](WORKFLOW.md).

| Раздел | Содержание |
| --- | --- |
| [Эксперименты](experiments/README.md) | Протоколы, расчёты и отчёты по проверенным гипотезам |
| [Стратегии](strategies/README.md) | Отобранные правила, сигналы Python и скрипты Pine для ручной сверки |
| [Paper trading](papertrading/README.md) | Конфигурации виртуальных счетов и порядок наблюдения за новыми сделками |
| [Критерии](criteria/README.md) | Оценка исторических кандидатов и результатов paper trading |
| [Сервис](service/README.md) | Опрос котировок, исполнение виртуальных заявок и журналирование |
| [Веб-панель](web/README.md) | Локальный просмотр стратегий, счетов, позиций и событий |
| [Тесты](tests/README.md) | Проверки сигналов, расчётов и сервиса |

## Начало работы

1. Запишите гипотезу и параметры в [эксперименте](experiments/README.md), затем сохраните результаты и ограничения в его отчёте.
2. Перенесите выбранное правило в [стратегию](strategies/README.md) с фиксированными параметрами и проверьте совпадение сигналов.
3. Создайте отдельный [виртуальный счёт](papertrading/README.md) и оценивайте новые сделки без подмены исторических результатов результатами paper trading.

Проверки из корня проекта:

```bash
python3 -m unittest discover -s tests -t .
```

Сейчас подключён источник котировок MOEX ISS. Для другого рынка потребуется адаптер данных и отдельная сверка календаря торгов, свечей, лотов и расходов. Локальные котировки, состояния счетов, журналы и крупные промежуточные файлы исключены из Git через [`.gitignore`](.gitignore); они не появятся после клонирования репозитория.
