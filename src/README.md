# Исследовательский код

| Папка | Назначение |
| --- | --- |
| [`ema/core`](ema/core/) | Загрузка исторических свечей, расчёт индикаторов, правила и бэктест EMA |
| [`ema/reports`](ema/reports/) | Сводки, сравнения и стресс-проверки результатов EMA |
| [`catalog`](catalog/) | Сборка единых README/CSV по фиксированным стратегиям и проверка структуры |

Это код исследований. Автоматический бумажный счёт находится в [`service`](../service/README.md), а его торговое правило — в `strategy.py` конкретной стратегии. Переборы и их результаты находятся в [`experiments`](../experiments/README.md).

Команды запускаются из корня репозитория через `python3 -m`, например `python3 -m src.catalog.check_ema_layout`. Исторический сборщик EMA использует MOEX ISS; бумажный сервис имеет отдельный [адаптер MOEX](../service/data_sources/README.md). Общий контракт свечей для этих двух путей пока не выделен, поэтому перед сопоставлением результатов нужна сверка времени свечи и модели исполнения.
