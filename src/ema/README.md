# EMA: исследования

[`core`](core/) содержит расчёт EMA, бэктесты и отдельные сочетания EMA с ADX, RSI, каналами и свечными паттернами. [`reports`](reports/) строит сравнительные и стресс-отчёты. Это повторно используемые инструменты исследования, а не активные торговые процессы.

Готовый сценарий прежнего массового пересчёта: [`scripts/run_ema_snapshot.sh`](../../scripts/run_ema_snapshot.sh). Полный новый перебор периодов лежит в [`experiments/ema-grid-search`](../../experiments/ema-grid-search/README.md).
