# Проверка шаблона экспериментов · 1 ноября 2026

Проверены 15 активных папок: 14 отдельных переборов и [сравнение SMA/ATR на SMLT](double-indicator/sma-cross-sideways-filters-smlt-1h/README.md). Скрытые исходные материалы `.history/` и служебные папки категорий не считаются текущими экспериментами.

## Общие артефакты

| Проверка по [шаблону](template/README.md) | Результат |
| --- | ---: |
| README с гипотезой/методом и командой запуска | 15/15 |
| Сводка `SUMMARY.md` | 15/15 |
| `results/manifest.json`, читаемый JSON | 15/15 |
| `results/progress.csv`, читаемый и непустой | 15/15 |
| Ссылка на проверки расчёта или команда тестов | 15/15 |

У Bollinger, CCI, Donchian, MACD, ROC, SMA и Williams нет отдельного `run.py` в папке: они запускают выбранное семейство через [общий расчёт индикаторов](../src/research/indicator_library.py). Команда и ссылка на код указаны в их README. Это соответствует требованию воспроизводимой команды, но структура папок отличается от экспериментов с собственным `run.py`.

Проверка выше охватывает **наличие и читаемость** базовых артефактов, не подтверждает корректность каждой сделки и прибыльность. Исторические поздние периоды уже просматривались, поэтому не являются слепым holdout. 15M и 30M остаются без результатов, пока нет [минутных свечей](../data/moex_scan/minute_coverage.json).

## Что ещё привести к шаблону при следующем переносе

- В 14 старых папках нет отдельной таблицы `cross_ticker_validation.csv`. Для широких переборов без зафиксированного кандидата она не требуется; при выборе `basket` или `universal` её нужно заполнить всеми заранее заявленными бумагами, включая убыточные и без данных. Уже рассчитанные полные CSV остаются исходными доказательствами.
- Только [EMA grid](ema-grid-search/candidate.json) хранит явный машинный паспорт выбранного варианта. Остальные исторически созданные стратегии ссылаются на строки экспериментов через README, но цепочка выбора оформлена неравномерно. Для **нового** переноса сначала сохранить паспорт кандидата и ссылку на точную строку, затем копировать Python и Pine.
- [Сравнение SMA/ATR](double-indicator/sma-cross-sideways-filters-smlt-1h/README.md) пока остаётся экспериментом: его 39 402 результата получены на просмотренном снимке, а кандидат для новой стратегии не зафиксирован. Текущий виртуальный счёт продолжает исходную SMA12/60.

[Машинный статус всех экспериментов](status.json) пересобран после окончания EMA-levels и включения сравнения SMA/ATR.
