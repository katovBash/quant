## Метод и контекст исходного исследования

# RSI без EMA · перебор

> Историческая запись: стратегии и виртуальные счета из этого исследования удалены 02.11.2026 после проверки месячного риска; результаты эксперимента сохранены.

Интервалы **15M и 30M** подключены к запуску этого эксперимента через минутные свечи MOEX. Исторические сводки выше относятся только к интервалам, фактически записанным в [manifest.json](results/manifest.json) и [progress.csv](results/progress.csv). Наличие исходных минутных данных проверяется в [общем JSON покрытия](../../data/candles/moex_scan/minute_coverage.json); отсутствие данных означает отсутствие теста, а не нулевую доходность. Загрузчик: `python3 scripts/fetch_minute_snapshot.py`; после появления минутного снимка команду перебора для этого индикатора запускают с `--timeframes 15M 30M`.

## Статус и гипотеза

Статус: **полный исторический перебор завершён 01.11.2026**. [Сводка по интервалам](SUMMARY.md), [полные таблицы](results/) и [покрытие](results/progress.csv). Малый запуск PLZL/VTBR 1H и 59 тестов проекта прошли перед стартом. RSI меняет режим после пересечения порогов: вверх — long, вниз — short. Не совмещаем сигнал с EMA или другими индикаторами. Контроль — покупка и удержание той же доли инструмента.

## Протокол до запуска

Источник — [снимок TQBR на 30.10.2026](../../data/candles/moex_scan/universe_2026-10-30.json). Все доступные акции из этого снимка; обычные свечи 1D, 1H и собранные из часовых 4H. Длина 7/14/21; пороги long/short 50/50, 55/45, 60/40. Для каждой настройки считаем long, short, long+short. Сигнал только по завершённой свече; виртуальное историческое исполнение на следующем открытии. Начальный капитал 1 млн ₽, позиция 25%, комиссия 0,05% за сторону, проскальзывание один тик. Округление до акции, без стоимости займа short и корпоративных событий. Период с 2025 года уже изучался ранее и **не является независимым holdout**.

## Код и тесты до полного запуска

Точка входа: [run.py](run.py); расчёт и единый формат строк: [`src/research/standalone_grid.py`](../../src/research/standalone_grid.py). [Шаблон проверки](../template/PROTOCOL_TEMPLATE.md). Тесты: `python3 -m unittest tests.experiments.test_standalone_grid tests.indicators.test_adx_rsi -v`. Малый запуск: `python3 experiments/rsi-grid-search/run.py --symbols PLZL VTBR --timeframes 1H --out /tmp/rsi-grid-search-smoke`. Только после успешного малого запуска: `python3 experiments/rsi-grid-search/run.py`.

## Результаты и решение

`results/manifest.json` — точные условия; `results/progress.csv` — все запланированные тикеры и интервалы, в том числе отсутствие данных; `results/<интервал>/<тикер>.csv` — **все** проверенные варианты и режимы. [SUMMARY.md](SUMMARY.md) показывает покрытие, фиксированные настройки на разных бумагах и предварительный топ тикеров по каждому интервалу. Устойчивость соседних параметров и независимая проверка на новых данных ещё не выполнены. Лучший максимум на просмотренной истории остаётся экспериментом; в `strategies/` переносим только зафиксированный вариант через [критерии](../../README.md).

Выбранный для ручной сверки вариант: README стратегии-кандидата. Полный перебор остаётся здесь; выбранная строка не подтверждает будущую прибыль.

Для SFIN отдельно сохранён [пересчёт с выплатой 902 ₽ на акцию 25.12.2025](SFIN_DIVIDEND_CHECK.md) и [скрипт воспроизведения](dividend_sensitivity.py). Выбранная RSI(21) 60/40 на 1H даёт +143,05% вместо исходных +173,85% при учёте только этой выплаты. Это не полный учёт расходов short.
