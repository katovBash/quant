## Метод и контекст исходного исследования

# MACD: перебор правил

Интервалы **15M и 30M** подключены к запуску этого эксперимента через минутные свечи MOEX. Исторические сводки выше относятся только к интервалам, фактически записанным в [manifest.json](results/manifest.json) и [progress.csv](results/progress.csv). Наличие исходных минутных данных проверяется в [общем JSON покрытия](../../data/candles/moex_scan/minute_coverage.json); отсутствие данных означает отсутствие теста, а не нулевую доходность. Загрузчик: `python3 scripts/fetch_minute_snapshot.py`; после появления минутного снимка команду перебора для этого индикатора запускают с `--timeframes 15M 30M`.

Отдельный эксперимент по индикатору **MACD**. Проверены семейства macd_cross, macd_zero: **20 заранее заданных правил** на 258 акциях TQBR и интервалах 1H, 4H, 1D (где доступны свечи). Это исследование, не стратегия для торговли.

[Сводка](SUMMARY.md) · [Все настройки](RULES.md) · [Покрытие](results/progress.csv) · [Условия](results/manifest.json) · [Тесты сигналов](../../tests/experiments/test_indicator_library.py)

Сигнал берётся на закрытой свече, виртуальное исполнение — на следующем открытии. Комиссия 0,05% за сторону, проскальзывание один тик, позиция 25% капитала. Стоимость займа и дивиденды short не учтены. Поздний период уже просмотрен, поэтому не является независимой проверкой. Правила считаются кодом [расчёта](../../src/research/indicator_library.py). Повторный запуск: `python3 -m src.research.indicator_library --indicator macd`.

## Long и short по отдельности

[Пересчёт направлений](results/trade_side_summary.csv) сделан для **10 показанных в помесячном отчёте примеров**, а не для всей сетки MACD. Для них отдельно рассчитаны `long_only`, `short_only` и исходный `long_short`; [таблица с каждой парой и процентом успешных закрытых сделок](results/REPORT.md#long-и-short-по-отдельности) находится в конце отчёта. По этим десяти примерам суммарно: long — 114 прибыльных из 276 закрытых сделок (41,3%), short — 141 из 283 (49,8%). Это доля сделок на выбранных после просмотра случаях, а не оценка преимущества short по всем акциям. Для остальных вариантов направленный пересчёт отсутствует; рекомендацию по всей сетке делать нельзя.
