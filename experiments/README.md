# Эксперименты

[Проверка всех активных экспериментов по шаблону](TEMPLATE_AUDIT_2026-11-01.md).
[Покрытие тикеров и связь экспериментов со стратегиями](STRATEGY_COVERAGE.md) пересчитывается из фактических результатов.

Здесь проверяем гипотезы и сохраняем **все** результаты, в том числе убыточные. Исторический максимум после перебора не означает, что правило работает на новых данных.

## Навигация по типу правила

- [Один индикатор или один тип сигнала](single-indicator/README.md): завершённые переборы EMA, RSI, ADX, каналов, уровней и других самостоятельных подходов, включая [пробой границ 1D/1W](single-indicator/htf-level-breakouts/README.md).
- [Два индикатора или фильтр сигнала](double-indicator/README.md): SMA с фильтрами, EMA с фильтром эффективности движения и EMA25 с линиями 1D/1W. [Как проверяем связь](INDICATOR_RELATIONSHIPS.md).
- [Режимы рынка](market-regime-grid-search/README.md): отдельное исследование фаз и перехода из боковика, без торговых сделок.
- [Периоды Turtle](turtle-period-grid/README.md): сетка входов и выходов, сравнение на 1H/4H/1D, временные окна и чувствительность к расходам.

Прежние 15 стратегий удалены после проверки месячного риска. Исходные эксперименты и [снимок их аудита](.history/retired-strategy-audit-2026-11-02/) сохранены для воспроизводимости; новые гипотезы проходят месячный экран до переноса в `strategies/`.

Для каждого текущего индикатора код принимает **15M и 30M** дополнительно к прежним 1H/4H/1D. Они строятся только из минутного снимка MOEX; [JSON покрытия минутных данных](../data/moex_scan/minute_coverage.json) и [статус всех экспериментов](status.json) показывают, какие расчёты действительно выполнены. Обновить статусы: `python3 scripts/check_minute_coverage.py` и `python3 scripts/report_experiments.py`. Старые `SUMMARY.md` остаются снимками прежних запусков и не становятся результатами 15M/30M автоматически. Загрузка минутных свечей: `python3 scripts/fetch_minute_snapshot.py`; команда может потребовать значительного времени и доступа к ISS. [Описание сборки свечей](../src/research/timeframes.py).

При частичном повторном запуске `manifest.json` сохраняет объединённый список тикеров и интервалов прежних и новых попыток; изменение параметров торгового протокола в той же папке результатов отклоняется. Фактическое покрытие берите из CSV результатов и [status.json](status.json), а не из одного только списка в манифесте.

## Каталоги

Все текущие расчёты одного семейства перечислены в [одиночных экспериментах](single-indicator/README.md). Сравнения двух индикаторов, включая [EMA25 + линии старшего периода](double-indicator/ema25-higher-timeframe-lines/README.md), находятся в [двойных экспериментах](double-indicator/README.md). Исследование [фаз рынка](market-regime-grid-search/README.md) и [переходов из боковика](market-regime-grid-search/TRANSITION_SUMMARY.md) хранится отдельно, потому что там прогнозируются события без сделок.

Снимок списка бумаг находится в [`data/moex_scan`](../data/moex_scan/universe_2026-10-30.json); код эксперимента не зависит от старого архива.

## Единый формат нового эксперимента

Создаём `experiments/<имя>/` по [шаблону](template/README.md):

```text
README.md       гипотеза, метод и навигация (без меняющихся чисел)
run.py          воспроизводимый запуск из корня проекта
results/        manifest.json, progress.csv и результаты по каждому тикеру/интервалу
candidate.json только если выбрано фиксированное правило для ручной проверки
```

В `manifest.json` фиксируем область поиска, периоды и интервалы; `progress.csv` и полные CSV хранят фактическое покрытие и результаты. README объясняет метод и даёт ссылки, а созданная после завершения сводка — снимок конкретного запуска. Выбранную пару без изменения проверяем на заранее названных других бумагах и новом периоде; отмечаем, какие данные уже были просмотрены. [Критерии переноса](../criteria/README.md) решают, можно ли создать кандидата в `strategies/`. Запуск paper trading — отдельный следующий шаг после ручной проверки.

Прежние файлы оставлены в скрытой `.history/` лишь для проверки происхождения старых цифр. Они не являются текущими экспериментами. Новые RSI, ADX, уровни и паттерны считаются **отдельно**, без комбинаций с EMA; сочетания будем проверять следующим этапом.
