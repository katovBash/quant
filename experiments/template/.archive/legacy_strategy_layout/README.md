# Название и версия стратегии

## Правило

Точное условие входа и выхода на закрытой свече; направление, таймфреймы, размер позиции, лот, комиссии и проскальзывание. Код для TradingView: [strategy.pine](strategy.pine).

## Результаты по акциям

[results.csv](results.csv) содержит **каждый тикер из фиксированного списка акций** и каждый предусмотренный интервал. Статус `historical_test` допускается только после расчёта именно этой реализации; для остальных строк используйте `not_tested` и оставляйте метрики пустыми. Не переносите результаты другой стратегии или другого направления.

Минимальные столбцы: тикер, компания, таймфрейм, статус, визуальная метка результата, доходность, число закрытых и прибыльных сделок, win rate, profit factor, просадка, начало и конец данных, источник. 🟢 означает положительный исторический результат при наличии закрытых сделок, 🔴 отрицательный, ⚪ теста или закрытых сделок нет. Это не допуск к торговле. Укажите период, комиссию, модель исполнения и ограничения сравнения с TradingView.

В README покажите топ‑5 положительных результатов отдельно для 1H, 4H, 1D и 1W, если этот интервал допускается стратегией и есть результаты. Рядом с доходностью всегда показывайте число сделок и прибыльных сделок; малую выборку помечайте явно.

## Проверка

Вставьте [strategy.pine](strategy.pine) в Pine Editor на выбранной акции и таймфрейме. Зафиксируйте, сверены ли сделки Pine с локальным расчётом. Критерии paper trading находятся в [общем протоколе](../../../../criteria/README.md). Старые картинки и подробные отчёты храните в архиве исследования, а не в видимой папке стратегии.
