# Три публичных торговых правила на акциях MOEX

Сравнение механических версий правил Ричарда Денниса (Turtles), Ларри Коннорса (RSI2) и Линды Рашке (Holy Grail). Это выбор **трёх известных авторов с опубликованными правилами**, а не рейтинг «лучших трейдеров мира» по доходности.

Источник: локальный снимок MOEX ISS от 2026-10-30. Проверяем все акции TQBR с пригодной историей: 1D, 1H и 4H; настоящих минутных свечей для 15M/30M в снимке нет. Полная сетка, формулы адаптаций, период и ограничения записаны до прогона в [protocol.json](protocol.json).

Публичные исходные описания: [Turtle rules](https://www.turtletrader.com/rules/), [Connors RSI2](https://tradingmarkets.com/recent/how_to_enter_and_exit_a_position_on_the_close-677551), [интервью Расшке](https://lindaraschke.net/wp-content/uploads/2013/12/raschke_pt2_0304.pdf). Источники описывают исходные правила; тест переносит их на акции MOEX и другие интервалы, поэтому не является результатом самих авторов.

Запуск из корня: `python3 experiments/three-trader-rules/run.py`. Пробный прогон: та же команда с `--smoke`.

Главная метрика — каждый полный календарный месяц непрерывного виртуального счёта на одной бумаге, включая стоимость открытых позиций. Капитал 1 млн ₽ и 25% на сделку **для каждой пары отдельно**. Комиссия, проскальзывание, дивиденды и стоимость шорта не включены: все доходности `gross_before_costs` и только для исследовательской сверки. Результаты по нескольким бумагам нельзя сложить в результат одного счёта.

После запуска: [REPORT.md](results/REPORT.md), [все пары](results/all_variants.csv), [все месяцы](results/monthly_returns.csv), [сводка по месячным кейсам](results/monthly_case_summary.csv), [годовые итоги](results/yearly_returns.csv), [окна по 100 сделок](results/trade_windows_100.csv), [покрытие](results/coverage.json), [пропуски](results/skipped.csv). Прошедшая историческая выборка помечена как `seen_history`; никакого автоматического переноса в стратегии или paper trading.

Для ручной проверки в TradingView: [Pine Script с переключателем всех шести вариантов и контроля](three_trader_rules_review.pine). Открыть тикер MOEX на `1H`, `4H` или `1D` и выбрать правило в настройке `Rule`; начальное значение — Turtle 20/10. Pine использует те же формулы на свечах графика, но результаты могут отличаться из-за границ 4H свечей, глубины истории и биржевых корректировок TradingView. Скрипт сохранён для ручного просмотра, без автоматического подключения к paper trading.

## Результат запуска 2026-11-04

Проверено 446 бумаг на 1D и по 263 на 1H/4H: 6804 пары «бумага × интервал × вариант», 173572 полных месячных строки и 58263 скользящих окна по 100 закрытых сделок. Проверка покрытия прошла; ошибок расчёта 0. Из исходных 505 SECID у 59 нет пригодной дневной истории оценки, для ещё 183 нет часовых свечей. Все причины записаны в `results/skipped.csv`.

| Вариант | 1D: медиана прибыльных месяцев | 1H | 4H |
| --- | ---: | ---: | ---: |
| Buy and hold 25% · контроль | 39,4% | 42,4% | 40,0% |
| Turtle 20/10 | 43,3% | 45,5% | 51,5% |
| Turtle 55/20 | 30,3% | 48,5% | 45,5% |
| Connors RSI2 <5 / >70 | 0% | 45,5% | 21,2% |
| Connors RSI2 <10 / >70 | 3,0% | 48,5% | 24,2% |
| Raschke ADX30 | 0% | 27,3% | 15,2% |
| Raschke ADX35 | 0% | 21,2% | 12,1% |

Часовые варианты выглядят интереснее на просмотренной истории, но это **не прогноз прибыльного первого месяца**. Пример без выбора одной экстремально выросшей бумаги: WUSH 1H Turtle 20/10 — 26 прибыльных месяцев из 33, 283 закрытые сделки, +879595 ₽ за весь период до расходов; худший месяц −39156 ₽. Контроль по WUSH имел 12 прибыльных месяцев. Другой тип правила: SVCB 1H Connors RSI2 <5 — 25 из 33, 101 закрытая сделка, +144018 ₽; худший месяц −3028 ₽. Результаты по SFIN и другим бумагам с резкими корпоративными событиями требуют отдельной сверки исходных свечей.

Варианты **не проходили независимый тест на новых данных**. У часовых версий правила измеряются в 20/55/200 часовых барах, что существенно меняет исходные дневные стратегии. Комиссия и проскальзывание особенно важны для частых входов; короткие позиции дополнительно требуют проверки доступности и стоимости займа. Ранжирование остаётся `REVIEW_ONLY`.
