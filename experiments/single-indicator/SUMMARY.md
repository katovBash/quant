# Один индикатор или один тип сигнала

Здесь индекс самостоятельных экспериментов: каждый проверяет одно семейство правил без фильтра из другого индикатора. Полные CSV и итоговые `SUMMARY.md` либо `REPORT.md` находятся внутри папки каждого эксперимента.

| Семейство | Эксперимент | Результат |
| --- | --- | --- |
| Скользящие средние | [SMA: пересечение](../sma-grid-search/SUMMARY.md) | [Сводка](../sma-grid-search/SUMMARY.md) |
| Осциллятор | [RSI](../rsi-grid-search/SUMMARY.md) | [Сводка](../rsi-grid-search/SUMMARY.md) |
| Импульс | [ROC](../roc-grid-search/SUMMARY.md) | [Сводка](../roc-grid-search/SUMMARY.md) |
| Импульс | [MACD](../macd-grid-search/SUMMARY.md) | [Сводка](../macd-grid-search/SUMMARY.md) |
| Ценовые уровни | [Пробой границ 1D/1W](htf-level-breakouts/SUMMARY.md) | [Помесячный отчёт](htf-level-breakouts/results/REPORT.md) |

ADX с +DI/−DI и MACD со своей сигнальной линией остаются одним **семейством индикатора**. Пересечение двух средних также считается одним семейством.
