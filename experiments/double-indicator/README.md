# Два разных индикатора

Здесь лежат эксперименты, в которых один сигнал допускает или отклоняет другой либо добавляется зона подтверждения. Прибыль из одиночных переборов нельзя выдавать за результат их сочетания.

- [SMLT 1H: SMA12/60 с ADX и зоной ATR; перебор пар SMA 2–200](sma-cross-sideways-filters-smlt-1h/README.md) · [сводка](sma-cross-sideways-filters-smlt-1h/SUMMARY.md). Прежняя стратегия исключена после проверки месячного риска.
- [EMA12/33 + фильтр эффективности движения](ema-efficiency-monthly/README.md): 10 акций, 1H, 50 строк, новый месячный экран; кандидат не найден.
- [EMA25 + уровни старших периодов](ema25-higher-timeframe-lines/README.md): полный перебор 100 акций на 1H/4H, включая локальные 4H линии и внешние зоны 1D/1W; [помесячный отчёт внешних зон](ema25-higher-timeframe-lines/results/outer_daily_weekly/REPORT.md). Внешние зоны резко сокращают сигналы, но по всей выборке не улучшают долю прибыльных месяцев.

## Пары для проверки

| Пара | Проверяемая связь | Контроль |
| --- | --- | --- |
| EMA-пересечение + RSI | Пересечение даёт направление, RSI допускает вход только в заданном диапазоне | Та же EMA без RSI |
| EMA-пересечение + ADX | Пересечение даёт направление, ADX задаёт минимальную силу движения | Та же EMA без ADX |
| EMA как уровень + RSI | Касание EMA даёт сигнал, RSI отсекает часть касаний | Та же EMA-зона без RSI |
| Четырёхточечные уровни + EMA | Отскок от уровня допускается только при согласованном положении цены относительно EMA | Те же уровни без EMA |
| Пробой канала + ADX | Пробой допускается при заранее заданной силе движения | Тот же пробой без ADX |
| Боковой режим + EMA | Фаза рынка служит фильтром EMA-сигналов | Та же EMA без фильтра фаз |

Пары в таблице выше — **гипотезы**, а не результаты. Перед запуском для каждой пары нужна отдельная папка по [общему шаблону](../template/README.md), точное правило соединения, диапазон параметров и собственные тесты. [Протокол сравнения](../INDICATOR_RELATIONSHIPS.md) определяет метрики и порядок отбора.
