# Архив наблюдений и отбора для paper trading

Эти материалы описывают **исторические исследования**, не текущие виртуальные счета:

- [Кандидаты](CANDIDATES.md) — сравнение диапазона, объёма и Heikin Ashi.
- [Список наблюдения](WATCHLIST.md) — старые приоритеты по тикерам, включая GAZP и VTBR.
- [Стресс‑расчёты](STRESS.md) — чувствительность выбранных прототипов к комиссии и проскальзыванию.
- [Пустой шаблон ручного журнала](manual_trade_log_template.csv) — для отдельного ручного счёта TradingView; не журнал автоматического PLZL.
- [Раннее наблюдение VKCO 1D](../legacy-ema/papertrading/README.md) — прежний план, не автоматический счёт.

Фразы «активная гипотеза VKCO» в первоначальных отчётах относятся к тому историческому плану. Текущий автоматический счёт и его стратегия указаны в [papertrading](../../../papertrading/README.md). Доходности здесь получены на уже просмотренной истории.
