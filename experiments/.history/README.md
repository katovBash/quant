# Архив экспериментов

Эти материалы сохранены как исходные результаты и не считаются текущими экспериментами единого формата. Их названия `success`, `candidates` и `watchlist` отражают старый исторический отбор, а не подтверждённую доходность или запущенный счёт.

| Материалы | Зачем сохранены | Текущий статус |
| --- | --- | --- |
| [Legacy EMA](legacy-ema/README.md) | Старые отчёты по кроссам, а также EMA + ADX/RSI, поддержка, паттерны и гибриды | Чистые кроссы 2–200 пересчитаны в [новом эксперименте](../ema-grid-search/README.md); остальные идеи требуют повторного теста |
| [Rule reviews](rule-reviews/README.md) | Таблицы по 21 ранее рассмотренному правилу, Pine-прототипы и топ‑5 | Исторический обзор, не 21 выбранная стратегия |
| [Paper trading notes](papertrading-notes/README.md) | Прежние списки кандидатов, стресс-расчёты и ручной шаблон журнала | Не текущий виртуальный счёт; [живой журнал](../../papertrading/README.md) отдельно |

При новом тесте берём идею отсюда, создаём новую папку по [шаблону](../template/README.md), фиксируем параметры до запуска и сохраняем полную таблицу. Архивные файлы при этом не переписываем под новый вывод.
