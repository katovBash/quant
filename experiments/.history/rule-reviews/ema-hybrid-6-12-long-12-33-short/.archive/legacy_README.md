# EMA6/12 long + EMA12/33 short

**Статус на 01.11.2026:** локальный тест MOEX завершён на данных до 30.10.2026; Pine-скрипт сохранён, но его сделки в TradingView ещё не сверены с локальным расчётом. Фактические условия займа бумаги не проверены.

Асимметричная стратегия для акций MOEX. [Pine Script для TradingView](../strategy.pine), [полный результат по 1615 тикер-таймфреймам](../../../legacy-ema/6-12-long-12-33-short/execute/results.csv), [исторические кандидаты и README по тикерам](success/README.md), [воспроизводимый Python-тестер](../../../../../src/ema/core/hybrid_ema.py).

| Позиция | Вход после закрытия свечи | Выход после закрытия свечи |
| --- | --- | --- |
| Long | EMA6 пересекает EMA12 снизу вверх | EMA6 пересекает EMA12 сверху вниз |
| Short | EMA12 пересекает EMA33 сверху вниз | EMA12 пересекает EMA33 снизу вверх |

Встречный вход переворачивает позицию по открытию следующего бара. Если на одной свече одновременно есть два разнонаправленных входа, стратегия выходит в кэш. Сигналы только на закрытой свече. Размер новой позиции — 25% текущего капитала, целое число акций. Начальный капитал 1 млн ₽, комиссия 0,05% за сторону, проскальзывание 1 тик, без пирамидинга.

Правила исполнения и автоматического разворота `strategy.entry()` соответствуют [документации TradingView](https://www.tradingview.com/pine-script-docs/concepts/strategies/); источник локальных свечей — [MOEX ISS](https://www.moex.com/a8531).

## Результат исследования

Локальный тест MOEX ISS: данные до 30.10.2026, полный период с 01.01.2022 для 1D/1W/1M и с 01.01.2024 для 1H/4H. Поздний отрезок начинается 01.01.2025. Проверено 505 тикеров TQBR на 1D/1W/1M и 50 ликвидных на 1H/4H. Ниже основной вывод по дневным графикам; кандидаты отбирались при медианном дневном обороте ≥50 млн ₽ и ≥100 барах.

| Показатель, 1D | Результат |
| --- | ---: |
| Ликвидных бумаг с ≥100 барами | 81 |
| Положительная доходность позднего отрезка | 32 |
| Прошли дополнительные критерии `success` | 23 |
| Медиана поздней доходности всех 81 | 0,00% |
| Медиана поздней доходности 23 отобранных | +5,77% |

Критерии `success`: доходность выше нуля и выше удержания 25% капитала на полном и позднем отрезках; ≥10 закрытых сделок на полном и ≥3 на позднем; хотя бы одна прибыльная поздняя сделка; profit factor >1; максимальная просадка не глубже 30%. Кандидаты отсортированы по поздней доходности. Это **исторический отбор на уже просмотренных данных**, а не независимый прогноз. Числа 8/85 для EMA6/12 long и 31/85 для EMA12/33 short относятся к двум отдельным стратегиям; они не являются статистикой этой комбинации.

| [TATN](success/TATN/README.md) | +10,47% | +24,77% | +8,08% |
| [MGNT](success/MGNT/README.md) | +9,77% | +16,85% | +6,48% |

На VTBR за поздний отрезок новая стратегия дала +10,80% при 26 закрытых сделках, из них 10 прибыльных (38,46%). Отдельная EMA6/12 long дала +5,16%, отдельная EMA12/33 short +11,78%, симметричная EMA12/33 long+short +19,10%. Следовательно, на VTBR эта связка **не улучшила** лучшую из уже проверенных стратегий. На LKOH поздний результат −3,83%; бумага в `success` не вошла, хотя присланный скриншот для другой стратегии выглядел сильным. Положительный процент сделок сам по себе не определяет прибыльность: учитываются также размер выигрыша и убытка, затраты, просадка и число сделок.

По остальным таймфреймам в файле `execute/results.csv`: среди ликвидных бумаг с ≥100 барами поздняя доходность положительна у 24/60 на 1W, 8/47 на 1H и 31/47 на 4H. Для 1M доступной длины истории недостаточно для условия ≥100 баров. Четырёхчасовые свечи агрегированы из часовых свечей MOEX и могут не совпасть с сессиями TradingView.

## Воспроизведение

Из корня проекта, после выполнения массового `scan_ema.py` и наличия его кэша:

```bash
python3 hybrid_ema.py
```

Команда перезапишет `execute/results.csv`, `success/selected.csv` и README выбранных тикеров. Для проверки в TradingView вставьте `strategy.pine` в Pine Editor на нужном тикере и таймфрейме. Сравнивайте при одинаковой истории и настройках: MOEX ISS и TradingView могут расходиться из-за состава свечей, торговых сессий, обработки корпоративных действий и модели исполнения. Скриншотов TradingView именно этой комбинации пока нет; таблицы получены локальным расчётом.

Базовый расчёт **не включает** фактическую стоимость займа для short, доступность бумаги для шорта, дивидендные обязательства, налоги, реальный спред и влияние заявки на цену. Колонка с 20% годовых — стресс-сценарий, не тариф брокера. Следующая разумная проверка: зафиксировать эту стратегию до получения новых данных и повторить оценку на будущем участке без изменения правил, затем проверить фактические условия шорта и расхождение с TradingView по нескольким конкретным сделкам.
