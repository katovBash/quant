# EMA33/66 пересечение

**Статус на 01.11.2026:** сохранённая фиксированная стратегия для сравнения на VTBR и GAZP; численные результаты Strategy Tester для этой реализации не записаны. [Pine Script](../strategy.pine) лежит в подпапке `execute/`. [Вариант с фильтром 1W](../../ema-cross-33-66-weekly-filter/README.md) хранится отдельно.

## Где лежат варианты

| Путь внутри `33-66-cross` | Назначение |
| --- | --- |
| [strategy.pine](../strategy.pine) | Основная стратегия EMA33/66; Pine-файл лежит в `execute/` этой стратегии. Сигнал на 1D, без недельного фильтра. |
| [execute/variants/weekly-filter/](../../ema-cross-33-66-weekly-filter/README.md) | Вариант того же правила: вход на 1D только при подтверждении предыдущей закрытой недели. Внутри есть свой [strategy.pine](../../ema-cross-33-66-weekly-filter/strategy.pine). |
| [tickers/VTBR/](tickers/VTBR/README.md) | Ранняя версия для VTBR с отдельным [Pine-файлом](tickers/VTBR/code/strategy.pine); сохранена для сравнения, не смешивается с основной. |

Исследовательский Python pipeline находится в [корне проекта](../../../../../README.md): [scan_ema.py](../../../../../src/ema/core/scan_ema.py) и [run_ema_snapshot.sh](../../../../../scripts/run_ema_snapshot.sh). Его результаты нельзя автоматически приписывать этому Pine-варианту без сверки правил и сделок.

| Параметр | Правило |
| --- | --- |
| Направление | Только long |
| График | Обычные дневные свечи 1D |
| Вход | EMA33 пересекает EMA66 вверх; EMA12 > EMA33 и закрытие выше EMA33 |
| Выход по тренду | EMA33 < EMA66 либо закрытие ниже EMA66 |
| Защитный выход | Подтягиваемый стоп на расстоянии 3 × ATR14 |
| Размер | Не более 25% капитала; риск на входе по умолчанию 0,5% капитала |

**Недельный фильтр выключен и зафиксирован.** Вариант с ним лежит в отдельной папке.

Исполнение: сигнал после закрытия свечи, рыночный приказ на следующем баре; 1 млн ₽ начального капитала, комиссия 0,05% за сторону, проскальзывание 1 тик. `lotSize` — настройка исполнения: **1 для VTBR, 10 для GAZP**. Она не переключает правила стратегии. Отдельных подтверждённых чисел по VTBR и GAZP для этого фиксированного Pine-скрипта пока нет; не переносите доходность из другого варианта EMA на эту папку.
