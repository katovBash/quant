# VTBR · пересечение EMA33/66

**Статус:** вариант для сравнения с основным EMA12/33. Результаты на VTBR пока не записаны.

Файл: [strategy.pine](code/strategy.pine). Скопируйте код в Pine Editor на рублёвом графике `VTBR`, интервал **1D**. Режим входа зафиксирован как `33/66 cross`; размер лота — 1.

## Правила

- Вход: EMA33 пересекает EMA66 снизу вверх; EMA12 уже выше EMA33, дневное закрытие выше EMA33. Покупка моделируется на следующем баре.
- Выход: EMA33 ниже EMA66 либо закрытие ниже EMA66. Дополнительно действует подтягиваемый стоп 3 × ATR14.
- Длинная позиция без пирамидинга, расчёт риска 0,5% капитала и ограничение доли бумаги 25%.
- Дополнительный фильтр 1W по умолчанию отключён; он использует только завершённые недельные свечи.

Это более медленный сигнал смены тренда, чем EMA12/33. Его нужно сравнивать на **том же периоде** с одинаковыми затратами; меньше ложных входов и меньшая доходность не гарантированы.
