# EMA12/33 с фильтром EMA66

**Статус на 01.11.2026:** сохранённая фиксированная стратегия для сравнения на VTBR и GAZP; численные результаты Strategy Tester для этой реализации не записаны. [Pine Script](../strategy.pine) лежит в подпапке `execute/`. [Вариант с фильтром 1W](../../ema-cross-12-33-66-weekly-filter/README.md) хранится отдельно.

| Параметр | Правило |
| --- | --- |
| Направление | Только long |
| График | Обычные дневные свечи 1D |
| Вход | EMA12 пересекает EMA33 вверх; EMA33 > EMA66 и закрытие выше EMA33 |
| Выход по тренду | EMA12 < EMA33 либо закрытие ниже EMA66 |
| Защитный выход | Подтягиваемый стоп на расстоянии 3 × ATR14 |
| Размер | Не более 25% капитала; риск на входе по умолчанию 0,5% капитала |

**Недельный фильтр выключен и зафиксирован.** Вариант с ним лежит в отдельной папке.

Исполнение: сигнал после закрытия свечи, рыночный приказ на следующем баре; 1 млн ₽ начального капитала, комиссия 0,05% за сторону, проскальзывание 1 тик. `lotSize` — настройка исполнения: **1 для VTBR, 10 для GAZP**. Она не переключает правила стратегии. Отдельных подтверждённых чисел по VTBR и GAZP для этого фиксированного Pine-скрипта пока нет; не переносите доходность из другого варианта EMA на эту папку.
