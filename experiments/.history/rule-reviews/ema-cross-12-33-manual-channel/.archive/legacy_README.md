# EMA12/33 + канал по заданным точкам

Этот вариант предназначен для проверки **твоих** наклонных линий VTBR. При добавлении [Pine](../strategy.pine) в TradingView выбери четыре точки: две на верхней линии (A, B) и две на нижней (A, B). TradingView позволяет задавать пары цена/время прямо щелчком на графике. Существующие ручные рисунки скрипт не читает, поэтому точки нужно поставить ещё раз. [Документация TradingView по интерактивным входам](https://www.tradingview.com/pine-script-docs/concepts/inputs/).

После последней из четырёх точек EMA12/33 даёт направление: long только в нижних 35% канала, short только в верхних 35%. Ширина канала должна составлять хотя бы 3% цены; встречное EMA пересечение закрывает старую позицию. До последней точки сделки запрещены, чтобы тест не использовал линию, нарисованную по будущим данным.

[Тикеры](tickers/README.md) · [success](success/README.md). Массового скана здесь нет: он требует отдельных четырёх исторических точек для каждой бумаги. Результат автоматического канала по экстремумам находится в [другой стратегии](../../ema-cross-12-33-channel-zone/README.md) и к твоим линиям VTBR не относится.
