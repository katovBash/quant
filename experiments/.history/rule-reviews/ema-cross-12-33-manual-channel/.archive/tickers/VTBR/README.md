# VTBR · ручной канал + EMA12/33

Открой `RUS:VTBR` в TradingView и добавь [Pine](../../../strategy.pine). По [скриншоту](../../../../../legacy-ema/12-33-cross/execute/variants/long-short/execute/variants/channel-zone-filter/execute/evidence/vtbr-manual-channel-2026-11-01.png) выбери четыре **исторические** точки: верх A/B и низ A/B. Лучше использовать точки на уже состоявшихся касаниях, а не будущий конец продолженной линии. После добавления проверь, совпадают ли построенные красная и зелёная линии с твоим рисунком; затем сравни сделки с чистой EMA12/33 при той же дате начала.

Цифр прибыли этого ручного варианта пока нет: точные координаты четырёх точек на скриншоте нельзя надёжно прочитать. Статистика автоматического pivot-канала к этим линиям не относится.
