# EMA12/33 long + short · трендовые линии

Самостоятельный фильтр входа. Экстремум считается подтверждённым только после трёх следующих закрытых свечей. Линия сопротивления проводится через два последних подтверждённых максимума, линия поддержки — через два последних подтверждённых минимума. При пересечении EMA12/33 вверх long разрешён, если close выше продолженной линии сопротивления; при пересечении вниз short разрешён, если close ниже продолженной линии поддержки. Если двух экстремумов нет, вход пропускается. Обратное пересечение всегда закрывает старую позицию.

Это математически определённые линии, а не вручную нарисованные. Их наклон может быть любым. Использование только подтверждённых экстремумов исключает заглядывание вперёд в локальном тесте. Различия в свечах и правилах обработки равных максимумов могут дать расхождения с TradingView. Short не включает стоимость займа и дивидендные обязательства.
