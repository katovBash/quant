# Отскок от EMA33 · фильтр 1W

**Статус на 01.11.2026:** сохранённая фиксированная стратегия для сравнения на VTBR и GAZP; численные результаты Strategy Tester для этой реализации не записаны. [Pine Script](../strategy.pine) лежит в подпапке `execute/`. [Вариант без фильтра 1W](../../ema-support-33/README.md) хранится отдельно.

| Параметр | Правило |
| --- | --- |
| Направление | Только long |
| График | Обычные дневные свечи 1D |
| Вход | Бычья свеча касается EMA33 в пределах 0,25 ATR14 и закрывается выше EMA33 и EMA12; EMA33 > EMA66 и EMA12 > EMA33 |
| Выход по тренду | EMA12 < EMA33 либо закрытие ниже EMA66 либо недельный фильтр перестал выполняться |
| Защитный выход | Подтягиваемый стоп на расстоянии 3 × ATR14 |
| Размер | Не более 25% капитала; риск на входе по умолчанию 0,5% капитала |

**Недельный фильтр включён и зафиксирован:** EMA33 завершённой недели > EMA66 и недельное закрытие > EMA33. При потере этого условия long закрывается. Используется только предыдущая завершённая неделя.

Исполнение: сигнал после закрытия свечи, рыночный приказ на следующем баре; 1 млн ₽ начального капитала, комиссия 0,05% за сторону, проскальзывание 1 тик. `lotSize` — настройка исполнения: **1 для VTBR, 10 для GAZP**. Она не переключает правила стратегии. Отдельных подтверждённых чисел по VTBR и GAZP для этого фиксированного Pine-скрипта пока нет; не переносите доходность из другого варианта EMA на эту папку.
