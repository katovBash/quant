# VTBR · чистое пересечение EMA12/33

**Основная стратегия по запросу пользователя.** Файл для TradingView: [strategy.pine](code/strategy.pine).

## Точные правила

1. График российской акции **VTBR**, интервал **1D**, обычные свечи.
2. EMA12 пересекает EMA33 **снизу вверх** на закрытой дневной свече → подать рыночную заявку на покупку. В тесте она исполняется на открытии следующего бара.
3. EMA12 пересекает EMA33 **сверху вниз** на закрытой дневной свече → закрыть всю позицию на открытии следующего бара.
4. Только длинная позиция, без повторного входа до закрытия. Других условий входа или выхода в этом варианте **нет**: EMA66, недельного фильтра и ATR-стопа здесь нет.

Размер позиции в тесте — 25% текущего капитала на входе. Начальный капитал — 1 000 000 ₽; комиссия — 0,05% с каждой стороны; проскальзывание — 1 тик. Эти параметры можно изменить в свойствах стратегии TradingView.

## Как сохранить и проверить

Откройте `VTBR` на 1D → Pine Editor → вставьте содержимое `strategy.pine` → Add to chart → Strategy Tester. Сравнивайте результаты на одинаковом диапазоне дат. Отдельно проверьте дни крупных гэпов и историю вокруг консолидации VTBR 2024 года.

Для локального бэктеста: `python3 quant.py backtest --symbol VTBR --mode cross12_33_pure`. Для таблицы сравнения: `python3 quant.py compare --symbol VTBR`.

| Показатель Strategy Tester | Значение |
| --- | --- |
| Диапазон дат | Не записан |
| Закрытых сделок | Не записано |
| Чистая прибыль | Не записана |
| Максимальная просадка | Не записана |

Этот вариант оставлен намеренно простым, чтобы видеть результат **самого пересечения**. Он создаёт тестовые ордера в TradingView и не отправляет реальные заявки брокеру. [Документация TradingView о стратегиях и исполнении ордеров](https://www.tradingview.com/pine-script-docs/concepts/strategies/).
