# EMA12/33 long-only и массовый скан TQBR

**Статус на 01.11.2026:** сохранена универсальная long-only стратегия и вариант VTBR 1D; массовый локальный скан завершён на данных до 30.10.2026. Числа Strategy Tester для исходного тикерного Pine не записаны и с локальными CSV отдельно не сверены.

Стратегия этого каталога: на закрытии бара EMA12 пересекает EMA33 снизу вверх — купить на открытии следующего бара; обратное пересечение — закрыть. **Только long**, без усреднения. [Универсальный скрипт TradingView](../strategy.pine) работает на любой акции и любом интервале. Исходный [вариант для VTBR](tickers/VTBR/code/strategy.pine) сохранён внутри этой стратегии. Для бумажной проверки VKCO нужен [отдельный фиксированный EMA12/33 long+short](../../ema-cross-12-33-long-short/README.md).

Автоматический расчёт по биржевым свечам выполняет [scan_ema.py](../../../../../src/ema/core/scan_ema.py). Итоги, список кандидатов, данные по каждому тикеру и графики находятся в [success](success/README.md), полная методика — в [research](../../../legacy-ema/12-33-cross/execute/research/README.md). Сканер проверяет все 45 пар из списка EMA 6, 12, 33, 66, 111, 222, 333, 444, 555, 666 в режимах long, short и long+short. Он не отправляет брокерские заявки.

Для TradingView есть [индикатор Pine Screener](../../../legacy-ema/12-33-cross/execute/screener.pine): он показывает win rate, число закрытых и прибыльных сделок для EMA12/33, а также текущий сигнал. [Pine Screener ограничивает расчёт последними 500 барами и не принимает strategy-скрипты](https://www.tradingview.com/support/solutions/43000742436-tradingview-pine-screener-key-features-and-requirements/), поэтому его показатели не должны совпадать с полным Strategy Report. Скрипт скринера предназначен для проверки списка символов внутри TradingView, а не для замены отчёта по всей истории.

Для сопоставления с TradingView установите 1 000 000 ₽, размер позиции `floor(25% капитала / close)`, комиссию 0,05% на сторону, проскальзывание 1 тик и тот же диапазон дат. В Python тик берётся из текущего справочника MOEX; история начинается в 2022 году, а первые `slow` баров используются для прогрева EMA. Поэтому результаты двух движков не обязаны совпадать. В TradingView также проверьте настройку корректировки на дивиденды, источник котировок, режим Deep Backtesting и время торговой сессии.
