# EMA12/33 long + short · фиксированная стратегия

**Именно эта стратегия выбрана для VKCO 1D в [paper trading](../../../legacy-ema/papertrading/README.md).** Вставьте [strategy.pine](../../../../../strategies/ema-cross-12-33-long-short/strategy.pine) в TradingView Pine Editor на графике `RUS:VKCO`, интервал 1D. В файле периоды EMA и оба направления уже зафиксированы; переключать режимы не нужно.

| Сигнал после закрытия свечи | Действие на открытии следующего бара |
| --- | --- |
| EMA12 пересекает EMA33 снизу вверх | Закрыть short, открыть long |
| EMA12 пересекает EMA33 сверху вниз | Закрыть long, открыть short |

Размер новой позиции — целое число акций на 25% текущего капитала, начальный капитал 1 млн ₽, комиссия 0,05% за сторону, проскальзывание 1 тик. `strategy.entry()` разворачивает позицию при встречном сигнале; исполнение по умолчанию моделируется на следующем баре согласно [документации TradingView](https://www.tradingview.com/pine-script-docs/concepts/strategies/). Скрипт не ограничен одним тикером, но зафиксированная ниже бумажная проверка относится к VKCO.

## Отличие от соседней папки

[Базовый `12-33-cross/execute/strategy.pine`](../../ema-cross-12-33-long/strategy.pine) — **только long**: по пересечению вверх покупает, по пересечению вниз закрывает позицию и остаётся без неё. [Этот `strategy.pine`](../../../../../strategies/ema-cross-12-33-long-short/strategy.pine) **разворачивается в short** при пересечении вниз. В [переключаемом тестере](../../../legacy-ema/12-33-cross/execute/variants.pine) можно сравнивать пары EMA и направления; для выбранного бумажного эксперимента используйте фиксированный файл из этой папки.
