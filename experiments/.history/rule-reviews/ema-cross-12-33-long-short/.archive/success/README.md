Для бумажной гипотезы VKCO есть [локальный результат MOEX](../../../ema-cross-12-33-long/.archive/success/VKCO/README.md), описанный в [README стратегии](../../README.md). Он ещё не сверён по сделкам с TradingView для этого файла.

После отдельной проверки укажите источник свечей, период, таймфрейм, число сделок и прибыльных сделок, доходность после издержек, просадку и profit factor.
